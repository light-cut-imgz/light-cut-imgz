Fonctionnalités

Recadrage

Tirez les huit poignées pour délimiter précisément la zone, avec une grille des tiers en repère.

Rotation

Par quarts de tour ou à l’angle de votre choix. Rendu en Rust, sans perte de qualité.

Export

Enregistrez en PNG, JPEG, WebP, BMP ou TIFF. Qualité réglable pour JPEG et WebP.

Installation

Recommandé

macOS & Linux — une seule commande

Homebrew sur Mac · .deb ou AppImage sur Linux — détection automatique 

curl -fsSL https://raw.githubusercontent.com/light-cut-imgz/light-cut-imgz/main/install.sh | bash
macOS → Homebrew Ubuntu / Debian → .deb Autres Linux → AppImage

ou installer manuellement

macOS — Homebrew

brew install --cask light-cut-imgz/tap/light-cut-imgz

Linux — Ubuntu / Debian (.deb) 

curl -fsSL -o light-cut-imgz.deb "$(curl -fsSL https://api.github.com/repos/light-cut-imgz/light-cut-imgz/releases/latest | grep -o 'https://[^"]*_amd64\.deb' | head -1)" && sudo apt install ./light-cut-imgz.deb

Linux — AppImage

mkdir -p ~/.local/bin && curl -fsSL -o ~/.local/bin/light-cut-imgz.AppImage "$(curl -fsSL https://api.github.com/repos/light-cut-imgz/light-cut-imgz/releases/latest | grep -o 'https://[^"]*_amd64\.AppImage' | head -1)" && chmod +x ~/.local/bin/light-cut-imgz.AppImage

Désinstallation

Recommandé

macOS & Linux — une seule commande

Retire l’application quelle que soit la façon dont elle a été installée. Vos réglages sont conservés. 

curl -fsSL https://raw.githubusercontent.com/light-cut-imgz/light-cut-imgz/main/uninstall.sh | bash

ou désinstaller manuellement

macOS — Homebrew

brew uninstall --cask light-cut-imgz

Linux — .deb

sudo apt remove light-cut-imgz

Linux — AppImage

rm ~/.local/bin/light-cut-imgz.AppImage
